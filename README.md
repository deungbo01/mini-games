# 🎮 미니게임천국 4.0 (HTML Mini-Games 4.0 Commercial Edition)

> **38종의 아케이드·퍼즐·전략·스포츠 미니게임을 외부 라이브러리 없이 단일 HTML 패키지(Zero-Dependency, 100% Offline PWA)로 구현한 웹 아케이드 플랫폼입니다.**

---

## ✨ 핵심 특징 (Key Features)

- **🕹️ 38종 올인원 미니게임 컬렉션**: 지뢰찾기, 블록블라스트, 스와이프 벽돌깨기, 2048, 수박 합치기, 타워 디펜스(22웨이브), 세로 슈팅(무한 오버드라이브), 핀볼(피버 잭팟), 스도쿠, 노노그램, 솔리테어 등 38개 정식 게임 수록.
- **🪙 통합 메타 경제 & 아케이드 상점 (`ArcadeEconomy`)**: 게임 플레이와 업적 달성으로 골드(`G`)를 획득하여 **프리미엄 테마 4종**(`사이버 네온`, `게임보이 1989`, `로열 골드`, `미드나잇 OLED`), **인게임 커스텀 스킨 4종**(`레이저 지뢰`, `드래곤 스네이크`, `사이버 닌자`, `골든 카드 덱`), **칭호 배지**를 해금·장착.
- **🎨 플랫폼 비종속 벡터 그래픽 (`ArcadeSprites`)**: OS별 기본 이모지 차이를 배제하고 정밀 인라인 SVG 및 Canvas 2D 벡터 렌더링으로 모든 기기에서 동일한 고해상도 비주얼 제공.
- **🎵 프로시저럴 신디사이저 BGM & 마스터링 오디오**: 외부 음원 파일 없이 Web Audio API로 실시간 합성되는 4종 테마 BGM(`Lo-Fi`, `Synthwave`, `Chiptune`, `Jazz`) + 5.2kHz Lowpass Biquad Filter 및 Dynamics Compressor 마스터링 체인.
- **🏆 58종 업적 · 일일 챌린지 · 50인 가상 리더보드 · SNS 스코어카드**: 달성한 기록을 1200×630 고해상도 이미지 카드로 즉시 생성·복사하고 JSON 파일로 세이브 데이터를 백업/복원 가능.
- **📲 100% 오프라인 PWA 지원**: 인터넷 연결이 끊겨도 모바일/데스크톱 앱처럼 설치 및 실행 가능.

---

## 🚀 바로 실행하기

1. **웹에서 바로 플레이**: GitHub Pages 활성화 시 `https://<내-깃허브-아이디>.github.io/<저장소-이름>/` 접속
2. **로컬에서 바로 실행**: 별도 서버나 설치 없이 `minesweeper.html` (또는 `index.html`) 파일을 더블클릭하여 브라우저로 열기

---

## 📦 파일 구성

| 파일명 | 설명 |
| :--- | :--- |
| `index.html` | GitHub Pages 루트 접속용 엔트리 페이지 (`minesweeper.html`로 즉시 연결) |
| `minesweeper.html` | 38종 게임 엔진·그래픽·사운드·상점·리더보드가 모두 담긴 단일 코어 파일 |
| `manifest.webmanifest` | 모바일/데스크톱 PWA 앱 설치 매니페스트 |
| `sw.js` | 오프라인 캐싱을 담당하는 Service Worker |
| `icon-192.png` / `icon-512.png` | PWA 앱 아이콘 |
